# DOCINT backend — pinned direct dependencies.
# Tested against Python 3.10+ on Linux. Install with:
#   python -m venv venv && source venv/bin/activate
#   pip install --upgrade pip
#   pip install -r requirements.txt
#
# GPU NOTE (read before deploying to a GPU server):
#   - torch/torchvision below already install CUDA-enabled Linux wheels from
#     plain PyPI (no extra index needed) — torch.cuda.is_available() will be
#     True automatically if an NVIDIA driver is present.
#   - surya (surya-ocr) runs on torch and picks up the GPU automatically once
#     torch sees it — nothing extra to do there.
#
# System (non-pip) requirements this project also needs on the server:
#   - Tesseract OCR binary on PATH (apt: tesseract-ocr) — used via pytesseract.
#   - Oracle 23ai reachable per backend/.env (ORACLE_* settings) — the
#     oracledb driver below runs in thin mode, no Oracle Instant Client needed.
#   - Redis reachable per backend/.env (REDIS_* settings) for the RQ job queue.
#   - Ollama running with the vision model pulled (see app/ai/ollama.py) for
#     the learned_anchor pipeline's cold-learning path.
